# 应急响应实战赛答题制策略

> 适用场景：比赛给被入侵服务器 + 基础提示，按题目问题提交答案自动评分。
> 与 CTF flag 制的根本区别：**答案是文本**（攻击者 IP / 文件路径 / 时间 / 漏洞名 / 持久化方式），不是 flag{...}。
> 京津冀决赛格式：3h10m，渗透赛 9:30-12:00 + 应急响应赛 12:20-15:30。

## 一、开局动作（前 10 分钟决定全局）

1. **读所有题目和提示信息**——不要上来就动手排查。题目给的提示往往直接指向事件类型和排查面。
2. **分型**：按现象关键词分到 7 类之一（勒索/挖矿/Webshell/篡改/DDoS/数据泄露/流量劫持）。
3. **优先级排序**：
   - 只需看日志就能答的题（攻击者 IP / 入侵时间）→ 最先做
   - 需要找文件的题（恶意文件路径 / webshell）→ 次之
   - 需要综合分析的题（漏洞 / 持久化 / 清除方案）→ 最后
4. **确认环境访问方式**：SSH？远程桌面？VNC？Web 终端？——决定用什么工具。

## 二、按面排查（每面限时 5 分钟）

### 面速查表（按优先级）

| 优先级 | 面 | 关键命令 | 能答的题 |
|---|---|---|---|
| 1 | 日志 | `grep -E "Accepted\|Failed" /var/log/auth.log` / nginx access.log / Windows 事件 4624 | 攻击者 IP / 入侵时间 |
| 2 | 文件 | `find /var/www -name "*.php" -mtime -30` / `grep -rE "eval\|assert\|system"` | 恶意文件路径 / webshell |
| 3 | 账号 | `cat /etc/passwd \| grep ":0:"` / Windows `net user` | 隐藏账号 |
| 4 | 进程 | `ps aux \| grep -v "\["` / Windows 任务管理器 | 恶意进程 / 挖矿 |
| 5 | 持久化 | `crontab -l` / `/etc/cron.*` / 注册表 Run 键 / `schtasks /query` | 持久化机制 |
| 6 | 网络 | `netstat -antp` / `ss -tlnp` | C2 连接 / 矿池 |

### 时间纪律
- 每面**限时 5 分钟**，无发现立刻换面
- 找到一条线索后**先答题**，再继续深挖（答案先拿分）
- 多题可共享同一次排查的发现——做笔记

## 三、答案格式（比赛常见丢分点）

| 问法 | 标准答案格式 | 丢分陷阱 |
|---|---|---|
| 攻击者 IP | 纯 IP 地址，如 `203.0.113.77` | 多写一个空格/逗号都可能判错 |
| 恶意文件路径 | 绝对路径，如 `/var/www/html/uploads/shell.php` | ❌ 补 `/var/www/html` 前缀（见路径纪律） |
| 入侵时间 | 日期+时间，如 `2026-09-15 03:45` 或 `2026/09/15 03:45` | 注意题干要求的时间格式；时区 |
| 漏洞 | 具体名称，如"文件上传漏洞" / "SQL注入" / "MS17-010永恒之蓝" | 太笼统（如"Web漏洞"）可能不给分 |
| 持久化 | 具体方式，如"crontab 定时任务" / "注册表 Run 键" / "隐藏账号" | 列出所有发现的持久化，不只写一种 |
| 清除方案 | 分步骤描述，含：杀进程→删文件→清持久化→修漏洞→加固 | 遗漏步骤=扣分；"重装系统"通常不给分 |

## 四、vulnclaw 执行策略

### SSH 环境下
```
remote_hosts          → 确认目标
remote_collect        → 一次性 33 段只读采集（最先做，现场固化）
remote_exec <命令>    → 逐面排查
```

### 本地/离线环境下
```
shell_command → 逐面排查
python_execute → 日志解析/批量文件扫描
load_skill_reference incident-response → 加载分型表和排查面指引
```

### IR 赛专用提示注入
解题时系统提示应包含：
- "这是应急响应赛：答案是文本，不是 flag"
- "每答一题立即可提交，不需要全部做完再交"
- "路径不许脑补——只能用命令输出的原样形式"（详见 incident-response SKILL.md 路径纪律节）

## 五、常见题型速答表

| 题型 | 一句话答案模板 | 证据来源 |
|---|---|---|
| "服务器被植入的后门文件路径" | find /var/www + grep webshell特征 | 文件排查面 |
| "攻击者的 IP 地址" | auth.log Failed/Accepted + nginx POST | 日志排查面 |
| "首次入侵时间" | 日志首条异常记录 / 文件创建时间 | 日志排查面 |
| "攻击者利用的漏洞" | 日志 payload 分析 + 恶意文件入口推断 | 综合分析 |
| "持久化方式" | crontab / systemd / 注册表 / 隐藏账号 | 持久化排查面 |
| "如何清除" | 分步骤：杀→删→清→修→加固 | 综合分析 |
| "恶意程序连接的矿池/C2地址" | netstat 出站 + 配置文件 | 网络排查面 |
| "勒索病毒家族" | 勒索信特征 + 加密后缀 | 特征比对 |

## 六、时间分配（3h10m 总量）

| 阶段 | 时长 | 动作 |
|------|------|------|
| 0-10min | 10min | 读题+分型+排序+确认环境 |
| 10-120min | 110min | 逐题排查+答题（每题限时 15min） |
| 120-160min | 40min | 攻坚分值高的综合题（清除方案/溯源） |
| 160-190min | 30min | 核查已交答案 + 补漏 |
