# CTF Endgame：差一步检查单

本技能覆盖一类高频失败：**漏洞已知、原语已通、却停在一块"想当然的墙"前**。
每条墙后面都埋过一个真实解。判死任何路径之前，对照本清单。

## 四个真实案例 → 四条硬规则

### 1. 平台拒值 ≠ 封路径（ezphp / 强网杯 PHP2shell）
第 1 轮走通 gopher 拿到值、平台判假旗；第 2 轮的 goal 写了"不要重验证 gopher 输出"
——把唯一活路当尸体埋了，165 个工具调用白跑。
**规则**：平台拒绝的是**值**，不是**路径**。重跑同一 vector，只变收尾假设
（编码 / 格式 / 目标文件 / 用哪个返回值），禁止在 goal 或 MISS 里封死 vector 本身。

### 2. 长输入之后必须 dump 状态（ByteDB / Crate-CTF）
查询字节直接写进 bytecode_map（缓冲区和映射表相邻），58 字节的合法输入溢出
改写了映射表前 7 项——不崩溃、不报错。上一轮只测了长度上限就断定"无溢出"。
**规则**：发送过任何长输入 / 变异输入之后，**立刻重新 dump 全部状态**
（映射表、配置、全局结构、选项菜单）——静默腐坏只会在状态转储里现形。
显式长度拒绝 ≠ 无溢出：检查看守的缓冲区和被溢出的缓冲区可能不是同一个。

### 3. "没有代码调用"必须枚举间接分发表（Celldelning / Crate-CTF）
"largebin attack 写的是堆指针，没有代码调用堆指针" ——漏了 printf 的
`__printf_function_table` / `__printf_arginfo_table`：把这两个 libc 全局指针
改成堆地址、在堆上伪造表项[%p]=win → 下一次 printf 即调 win。
House of Husk 是现代 glibc（无 hook）下"有堆写、无劫持点"的标准答案，
3 次 sort 恰好塞进 6 次 malloc 上限。
**规则**：宣判"无处调用"之前，逐项排查间接调用面：
printf/strftime specifiers 表、C++ vtable、locale、atexit/__exit_funcs、
宽字符表、dlsym 缓存。**能写 libc 的全局指针 = 能执行。**

### 4. 模板/蒙版不需要等比缩放（Owls and Dragons II / Crate-CTF）
thing.png（黑条+孔）因长宽比与字母格不符被放弃——官方解法就是非等比缩放
叠上去，孔中透出 steghide 密码。
**规则**：模板、蒙版、贴纸类资产**必须叠加到每一个候选表面上**，缩放比不必保形；
坐标对不上时先试旋转/平移/裁剪再放弃。

## 元规则：静态推演的墙要一次廉价证伪

在把任何路径记为 MISS / ruled-out 之前，回答一个问题：
**"证伪我这个断言，最便宜的实验是什么？"** 常见形态：

- 发完长输入 → dump 状态（规则 2）
- 宣判"无调用" → 枚举分发表（规则 3）
- 几何/对齐不匹配 → 试非等比/旋转/平移（规则 4）
- 平台拒值 → 换收尾假设重跑同 vector（规则 1）

拒绝做这个实验的判死，在 blackboard 里要用静态断言措辞——框架会在
MISS 响应里附加提醒，stall guard 会把它当作未证伪的假设对待。

## 附：看过 ≠ 看过等于没看（Vandraren / Crate-CTF）

视频第 448 帧有一张可读地图（湖名全国唯一），run 翻过帧却没有细看任何一帧。
**规则**：多帧/多页/多段资产，每一帧都要单独细读一遍（vision + OCR），
"浏览过全部"不算数——解 often 在单独某一帧里。
