## 二、网络安全法要点

- 第 21 条：国家实行**网络安全等级保护制度**（网络运行安全）。
- 第 25 条：制定网络安全事件应急预案，及时处置漏洞/攻击/入侵等风险。
- 第 41 条：收集使用个人信息应当**明示收集使用规则，并经被收集者同意**。
- 第 47 条：网络运营者应当加强其用户发布的信息管理（信息内容责任）。
- 关键信息基础设施运营者在网络安全等级保护制度基础上实行**重点保护**。

## 三、等级保护 2.0（等保）

- 核心标准：**GB/T 22239-2019**《信息安全技术 网络安全等级保护基本要求》，
  2019-12-01 实施（替代 GB/T 22239-2008，即等保 1.0）。
- 其他配套：GB/T 25070-2019（安全设计技术要求）、GB/T 28448-2019（测评要求）、
  GB/T 28449-2019（测评过程指南）。
- 五个等级：第一级（自主保护）→ 第五级（专控保护）。多数系统定二级或三级；
  常见考点：**第三级系统每年至少一次**等级测评，第四级每半年至少一次（依据
  《信息安全等级保护管理办法》公通字〔2007〕43 号）。
- 定级两要素：**受侵害的客体** × **对客体的侵害程度**（一般损害/严重损害/
  特别严重损害）。
- "一个中心、三重防护"：安全管理中心 + 安全通信网络/安全区域边界/安全计算环境。

## 四、应急响应

- 经典流程 **PDCERF** 六阶段：准备(Preparation) → 检测(Detection) → 遏制
  (Containment) → 根除(Eradication) → 恢复(Recovery) → 跟踪/总结(Lessons
  Learned / Follow-up)。
- 《国家网络安全事件应急预案》事件分级：**特别重大 / 重大 / 较大 / 一般**
  （四级），对应Ⅰ/Ⅱ/Ⅲ/Ⅳ级响应。
- 国家层面应急协调机构：中央网信办（国家互联网信息办公室）统筹协调；
  CNCERT/CC（国家互联网应急中心）负责监测/通报/处置支撑。

## 五、密码与国密算法

- 《密码法》密码分类：**核心密码、普通密码**（用于保护国家秘密）、
  **商用密码**（保护非国家秘密）。
- 国密算法：**SM2**（椭圆曲线公钥/非对称）、**SM3**（哈希，输出 256 位）、
  **SM4**（分组对称，分组 128 位/密钥 128 位）、SM9（标识密码）、ZUC
  （祖冲之序列算法，用于 4G/5G）。
- 对称：DES（56 位密钥，已不安全）、3DES、AES（128/192/256 位）、SM4、ChaCha20。
- 非对称：RSA、ECC、DSA、Diffie-Hellman、SM2。
- 哈希（不是加密）：MD5（128 位，已碰撞）、SHA-1（已碰撞）、SHA-2 系列、SM3。
- 常见混淆点：MD5/SHA/SM3 是**哈希**，选"加密算法"的题不要选它们。

## 七、其他高频记忆点

- 国家网络安全宣传周：每年 9 月举办，**通常为 9 月第三周**（具体以当年官方
  通知为准）。
- 首个《中国网络安全产业分析报告》类数字题不牢靠，不猜具体数字。
- ISO/IEC 27001：信息安全管理体系（ISMS）认证标准；27002：控制措施实践
  代码；等保是**中国法定制度**，27001 是国际标准，两者不是一回事。
- 《网络安全法》适用范围：在中华人民共和国境内建设、运营、维护和使用网络，
  以及网络安全的监督管理。
- 数据分类分级：数据安全法要求实行**数据分类分级保护制度**；核心数据实行
  更严格管理。
- 供应链/审查：网络安全审查重点评估**关键信息基础设施**采购网络产品和服务
  可能带来的国家安全风险。
- 常见端口速记：21 FTP / 22 SSH / 23 Telnet / 25 SMTP / 53 DNS / 80 HTTP /
  110 POP3 / 443 HTTPS / 445 SMB / 1433 MSSQL / 1521 Oracle / 3306 MySQL /
  3389 RDP / 6379 Redis / 8080 常见 Web 备用。
- 攻击概念对应：SQL 注入→拼接查询；XSS→注入脚本到页面（存储/反射/DOM）；
  CSRF→伪造用户请求；SSRF→服务端发起请求；DDoS→耗尽资源；钓鱼→社会工程。
