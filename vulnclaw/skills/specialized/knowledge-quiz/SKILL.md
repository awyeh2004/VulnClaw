# 知识竞赛 Skill

比赛里的知识竞赛（理论题）环节和攻防题完全不同：**得分来自答对题，而不是攻破靶机**。
题目通常是一次性给出的选择题/判断题/填空题，评分即交卷，没有环境可以"试出来"。

## 识别信号

输入或抓取到的页面出现以下任一特征，即按本策略处理：

- 明示"知识竞赛 / 理论题 / 单选 / 多选 / 判断题 / 填空题 / quiz"
- 题干 + `A. B. C. D.` 选项列表，或 `( )` + 对/错
- 题目问法律条文、生效日期、等级保护、应急流程、加密算法分类等**记忆型**内容

## 工作流

1. **先读完所有题** — 用 `fetch` 抓取答题页，把每道题的题干和选项完整记入证据。
   多页/多题时逐页抓全，不要答一题翻一页（可能漏题或触发跳转）。题目已直接
   粘贴在任务文本中时直接作答，无需抓取。
2. **判断题型与交卷格式** — 单选答一个字母、多选答全部字母、判断答 对/错
   （以平台要求为准，如"正确/错误"、"True/False"）。格式错了不得分。
3. **用自身知识作答** — 不要对答题平台做扫描/注入/爆破：那是别的赛道，这里
   唯一允许的交互是读题和交卷。涉及法律法规/等保/应急响应时，先
   `load_skill_reference` 读 `cn-cybersec-law-baseline.md` 对齐高频考点。
4. **超纲题兜底（关键）** — 超出自身知识的题目（当年时事、比赛主题/届数、
   训练截止后新发布的文件）**不要猜**：继续做完其余题目，每道超纲题用红色
   `🔴 超纲题` 前缀标记（题号 + 题干 + 选项原文），并附上相关资料线索：
   可能出处的法规/文件名、建议检索关键词、对应的 skill reference 文件、
   平台公告页。**全场做完后先不要交卷**：以 `🔴 超纲题汇总` 列出全部超纲
   题并 `ASK_USER:` 请用户作答；拿到用户答案后合并，再做唯一一次最终提交。
5. **不确定就排除法** — 删掉明显错误的选项后选最可能的；空题必零分，猜测
   期望分 > 0。宁可选一个相近答案，不要留空。（注意与第 4 条的边界：
   "没把握"用排除法，"知识范围外"转交用户。）
6. **按平台要求提交** — 交卷接口/表单字段按页面实际结构来，提交后核对返回
   的确认信息（得分/对题数）再收尾。

## 高频考点速记

- **法律法规**：网安法 2017-06-01 施行；数安法 2021-09-01；个保法 2021-11-01；
  密码法 2020-01-01；关基条例 2021-09-01（详见 reference）
- **等保 2.0**：GB/T 22239-2019，2019-12-01 实施；五个等级；定级两要素 =
  受侵害客体 + 侵害程度
- **应急响应**：PDCERF 六阶段（准备-检测-遏制-根除-恢复-跟踪）；事件四级
  （特别重大/重大/较大/一般）
- **加密基础**：DES/AES/SM4 对称；RSA/ECC/DSA/SM2 非对称；MD5/SHA/SM3 哈希
  （不是加密）；SM 系列为国密算法
- **常见端口**：22 SSH / 80 HTTP / 443 HTTPS / 3389 RDP / 3306 MySQL /
  6379 Redis / 1433 MSSQL
